# 成大午餐轉盤 NCKU Lunch Wheel

選擇困難？內建成大周邊 53 家餐廳資料庫，用評分、價位、營業時間篩選後，讓轉盤幫你決定今天吃什麼。  

👉 **線上試用：** https://ohreal1113.github.io/ncku-lunch-wheel/

> 本專案為「用 Vibe Coding 做出一個互動網頁」作業，透過與 AI 討論規格並反覆修改完成。整個網站只有一個 `index.html`。

## 一、發想動機
每天中午在成大附近都會陷入「要吃什麼」的選擇困難。  
希望做一個網頁：內建成大附近的餐廳資料庫，一次看評價、價格、地址和營業時間，把想吃的幾家丟進轉盤，轉一下就決定。  

## 二、目標使用者與情境
・成大學生：中午下課前打開手機，用評分、價位、營業中篩出幾家喜歡的店，轉盤 5 秒內幫忙決定。  
・一群同學：大家各自加入想吃的店，交給轉盤決定，避免爭論。  

## 三、功能規格
1. 內建餐廳資料庫  
   ・53 家成大周邊（1.2 公里內、中午有營業）的真實餐廳，資料整理自 Google 地圖（2026/10/19）。  
   ・每家店包含：店名、類型、所在路段、中文地址、Google 評分、評論數、價位、週一到週日營業時間，  
     以及距離成大的公尺數（由經緯度計算）。  
   ・8 種類型：台式便當、麵食、日式、早午餐、義式、異國、速食、健康餐。  
   ・使用者可以自己新增店家（店名、類型、價位、路段、地址、我的評分）；  
     自訂店家存在瀏覽器 localStorage，有「自訂」標籤，可刪除。  

2. 搜尋、篩選、排序（即時更新清單）  
   ・關鍵字搜尋店名或地址（例如輸入「勝利路52巷」）。  
   ・類型按鈕（顯示每類有幾家）、區域（育樂街/勝利路/大學路/東寧路/長榮路/其他）、  
     最低評分（4.0+/4.3+/4.5+）、價位（$200 以下）、「現在有營業」。  
   ・排序：依距離成大 / 依評分 / 依評論數 / 依價格。  

3. 店家清單  
   ・每一列顯示：店名、評分（評論數）、價位、類型、路段、距成大幾公尺、營業中/休息中、地址。  
   ・右邊「＋ 轉盤」可直接加入轉盤，已加入的會顯示「✓ 已加入」。  

4. 餐廳詳細資料  
   ・大字評分＋評論數、價位、類型、距成大幾公尺、現在營業中/休息中、地址。  
   ・一週營業時間表（今天那一列會標紅）。  
   ・按鈕：加入轉盤、在 Google 地圖看評論（另開新分頁）。  

5. 候選轉盤  
   ・可單獨加入，或一鍵把篩選結果全部加入（超過 20 家會先確認）。  
   ・Canvas 轉盤，按「開始轉！」、點中心「GO!」或空白鍵開始；4～5 秒逐漸減速，經過每格有「喀」聲。  
   ・停下時指針指到的店 = 抽中結果（已用自動化測試驗證一致）。  
   ・候選清單存在 localStorage，重新整理不會消失。  

6. 抽中結果  
   ・顯示店名、評分、價位、類型、距離；如果現在沒營業會出現「⚠️ 現在休息中」提醒。  
   ・用 Google 地圖導航 / 看這家的詳細資料 / 跳過再轉一次（點刪除線標籤可放回）。  

7. 其他：響應式設計（手機上下排列）、深色模式。  

## 四、技術規格
・單一 index.html，HTML + CSS + JavaScript 寫在同一檔；資料庫是寫在程式裡的 JavaScript 陣列。  
・營業時間格式：「週一|週二|…|週日」，每天可有多個時段，支援營業到半夜；  
  用目前時間計算「營業中/休息中」。  
・完全不呼叫外部 API，離線打開也能用；轉盤：Canvas 2D；音效：Web Audio API。  
・部署：GitHub Pages。  

## 五、和 AI 反覆調整的過程（Vibe Coding 紀錄）
1. 從 4 個點子（午餐轉盤、番茄鐘、打字遊戲、心情日記）中選定「成大午餐轉盤」。  
2. 第一版：手動維護店家清單＋預算/類型/區域篩選＋用餐紀錄統計。  
3. 發現 AI 預設的店名是編的 → 請 AI 用 Google 地圖搜尋，換成成大周邊 13 家真實店家。  
4. 覺得手動維護清單太麻煩、也看不到評價 → 想改成「在地圖上選餐廳、直接看評價和價格」，  
   刪掉手動清單、類型/區域分類、用餐紀錄，只保留「選店 → 轉盤」的核心流程。  
5. AI 先做了串接 Google Maps API 的版本，但 Google API 需要申請 Key、綁信用卡，  
   而且 Key 放在公開的 GitHub 上有被盜用的風險 → 改用免費的 OpenStreetMap 即時抓店家＋Google 嵌入卡片看評價。  
6. 實際打開後發現即時呼叫外部地圖服務常常失敗 → 決定改成「自己建立資料庫」：  
   請 AI 用 Google 地圖查詢成大 1.2 公里內的餐廳，整理出 53 家（評分、評論數、價位、營業時間），  
   直接寫進網頁裡。網頁不再依賴外部 API，評分、價位、營業中都能拿來篩選；  
   同時加上「自己新增店家」，讓資料庫可以擴充。  
7. 覺得地圖佔空間、底圖又常載不出來 → 請 AI 拿掉地圖，只留店家清單，改成每家店直接顯示中文地址，  
   地址也可以拿來搜尋。網頁從此不需要任何外部連線。  
8. 請 AI 用自動化瀏覽器測試：各種篩選與排序、營業中判斷（週一中午 47 家、下午 3:30 剩 25 家、  
   半夜 0 家）、用地址搜尋、新增與刪除自訂店家、轉 3 次結果與指針一致、跳過重轉、重新整理後資料仍在、  
   確認網頁沒有任何外部連線、手機寬度不會左右捲動。
